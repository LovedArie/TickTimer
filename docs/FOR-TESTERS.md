# TickTimer — how to run it (start here)

Hi! You're testing TickTimer. There's **one program to run** and nothing to
install. The part that stores your data lives online, so you don't have to
run or set up anything for it.

## The short version

1. Unzip this folder somewhere you'll find again (Desktop is fine).
2. Double-click **`TickTimer`**.
3. On the login screen, find the **Server** box near the bottom. It starts out
   saying `http://localhost:8080`. Replace that with:

   ```
   https://ticktimer.perryouy.com
   ```

4. Click **"New here? Create an account"**, pick a username and password,
   paste the **invite code** you were given, and you're in.

You only type the address **once** — the app remembers it from then on.

---

## About the invite code

Creating an account needs a short code — otherwise anyone who found the
address could sign up. Ask for it; it's one line, and you only need it once,
on the account-creation screen. Logging in afterwards never asks again.

If you see **"This server needs an invite code to create an account"**, that's
this — the box for it is on the same screen, straight below the password box.
It only appears once you've switched to account-creation mode.

---

## Ignore `Start TickTimer server`

There's a second program in this folder called **`Start TickTimer server`**.
**You don't need it.** It's there for running TickTimer entirely on your own
machine with no internet at all, which is not what you're doing. Starting it
by accident does no harm — just close the black window if one opens.

---

## Things that might go wrong

- **"Can't reach the server."** Nine times out of ten the **Server** box is
  still on its factory setting, `http://localhost:8080`, which means "look on
  this very computer" — and there's nothing there. Set it to
  `https://ticktimer.perryouy.com`, with the `https`, no trailing slash, no
  typos. If it already says that, check you're online.
- **"This server needs an invite code."** See above — you need the code to
  *create* an account.
- **Windows SmartScreen warning** ("Windows protected your PC"). Because this
  isn't a signed commercial app, Windows is cautious. Click
  **More info → Run anyway**. It's safe — it's just us.
- **A banner about a new version.** That means there's a newer build than the
  one you have. Click through to grab it whenever suits you; nothing breaks if
  you don't.

---

## Using it on your phone

You don't need this folder for that. Open
`https://ticktimer.perryouy.com/app/` in your phone's browser and log in with
the same account — it's the same app and the same data. (Android users can
also install a real APK; ask if you'd rather have that.)

## Share & compare (the fun part)

Once you're both logged in, click the **👥 Share** button in the app, type the
other person's username, and hit Share. Then they'll see a **Compare** button
next to your name — click it to see both your days side by side: the time
totals AND each person's schedule for the day (handy for spotting when you're
both free). Sharing is one-way, so you each share with the other if you both
want to see.
