Getting started — a quick guide for testing

Hi! You're helping test TickTimer, a little app for planning your day and seeing how your time actually gets spent. Setting it up takes about five minutes, and this guide walks you through every click. No technical knowledge needed.

The one rule to remember: TickTimer needs a server running before the app can log in — a bit like an online game needing its server up before you can join. On your side you only ever run the app; the server lives on your boyfriend's computer.

1 Unzip the folder

You were sent a file called TickTimer.zip.
  1. Find TickTimer.zip wherever you saved it (probably Downloads).
  2. Right-click it → Extract All… → Extract. Windows makes a normal folder called TickTimer next to the zip.
  3. Open that TickTimer folder. You'll see a lot of files — that's normal. You only care about one, coming up next.

2 Open the app

The file named TickTimer (it may show as TickTimer.bat).
  1. Double-click TickTimer. A login screen opens after a moment.
  2. Windows may show a blue box: “Windows protected your PC.” This is normal for a small app like ours — it just isn't a big commercial program Windows recognises. Click More info, then Run anyway. It's safe; it's just us.
If a firewall pop-up appears asking whether to allow the app through — you can click Allow, but it's harmless either way. (The firewall prompt that really matters is on your boyfriend's computer, not yours.)

3 Point the app at the server

This is the only spot where you type something specific.

On the login screen there's a box labelled Server. It starts out saying http://localhost:8080. That address means “this same computer” — but the server is on your boyfriend's computer, so you need to change it to his address.

  1. Ask him for his server address. He can read it off his own server window — it's the line that says “from another device.” It looks like this:
    http://192.168.1.40:8080
  2. Clear the Server box and type his address in exactly. (If you forget the http:// part, don't worry — the app adds it for you.)
  3. You both need to be on the same Wi-Fi for this to work. His computer and the server also need to be turned on and running at the time.

4 Make your account & log in

  1. Click “New here? Create an account.”
  2. Pick any username and password you like — they're yours, separate from his.
  3. Click Create account. You should land straight in your own planner. That's it — you're in! ♥

5 Try “Share & compare” together

The fun part — comparing your days side by side.
  1. In the app, click the 👥 Share button.
  2. Type his username and click Share. That lets him see your planner.
  3. For him to appear on your side, he shares with you too (sharing is one-way, so you each do it once). Then a Compare button shows up next to his name — click it to see both your days next to each other.
