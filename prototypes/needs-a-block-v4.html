1Two clocks, deliberately unsynchronised. The review re-arms at 06:00; a dismissal returns at 21:00. That gap is the feature — dismissing isn't "shut up", it's defer to a better moment, and the better moment for "I'm not doing this today" is while you're planning tomorrow, not the following morning after the day is already committed. Nothing stops you setting both to the same time; they just aren't wired together, so you're never forced to.

3Escalation is specificity, not volume. This partly reverses what v2 said about the gate always being free, so: the free bypass still holds for everything except a task that has earned escalation by being dismissed repeatedly while urgent. At that point "Not today" stops being one click and becomes a real choice — schedule it, push the deadline, or admit it isn't urgent. The last two change the data, which is the point: if you dodge something five times, either the deadline is wrong or the priority is. Dismissing again is still available; it just says the count out loud. A louder version of the same nag would only teach you to stop reading it.
4Where the escalation state lives. dismissCount is a fact about the task, so it belongs on Task and in the JSON — additive key, tolerant read, missing → 0, no migration, exactly like archived and priority before it. The rung is derived from it on every read, never stored: the same derive-don't-store rule that keeps Upcoming honest. Change the threshold in Settings and every task re-rungs itself instantly, with nothing to migrate — try it.

Still open

Two, and one of them is mine rather than yours.
  1. Does the escalation counter ever reset? Right now it only clears when the task actually gets a covering block. So a task you dismissed six times in May, then scheduled and finished, starts clean — but a long-lived recurring task could carry a decade-old count. Reset on completion is probably right; reset after N quiet days is the alternative.
  2. Should "push the deadline" be that easy? It's one click and moves the due date a week. That's honest — better than a fake deadline you keep blowing past — but it's also the path of least resistance in a menu designed to remove easy outs. Maybe it should ask for a specific date rather than defaulting to +7.
